# 02 · Mann–Kendall：趋势显著性

## 1. 它回答什么问题

“这个像元的上升/下降，是稳定的单调趋势，还是可以用随机波动解释？”

Mann–Kendall（MK）检验是**非参数**的单调趋势检验：不假定数据服从正态分布，
只比较“后一年是否大于前一年”。原假设 $H_0$ 是“序列不存在单调趋势”。

## 2. S 统计量

对每一对年份 $(i,j)$，$i<j$，定义

$$
\mathrm{sgn}(x_j-x_i)=
+1\quad(x_j>x_i),\qquad
0\quad(x_j=x_i),\qquad
-1\quad(x_j<x_i)
$$

$$
S=\sum_{i=1}^{n-1}\sum_{j=i+1}^{n}\mathrm{sgn}(x_j-x_i)
$$

- $S>0$：后期值总体高于前期值，上升倾向；
- $S<0$：下降倾向；
- $S=0$：上升与下降配对相互抵消。

$S$ 的取值范围是 $[-n(n-1)/2, n(n-1)/2]$。$n=22$ 时是 $[-231, 231]$。

## 3. 方差与 ties 修正

若序列独立且无重复值，

$$
\mathrm{Var}(S)=\frac{n(n-1)(2n+5)}{18}
$$

真实数据常有重复值（ties），例如 NDVI 转成整数、GPP 为整数、降水为 0。
重复值会减少 $S$ 的有效变异，必须修正：

$$
\mathrm{Var}(S)=\frac{n(n-1)(2n+5)-\sum_{p=1}^{g} t_p(t_p-1)(2t_p+5)}{18}
$$

其中 $g$ 是不同取值的组数，$t_p$ 是第 $p$ 组的重复个数。
若所有年份取值都相同，则 $\mathrm{Var}(S)=0$，检验无定义；本仓库规定
$Z=0$、$p=1$，归入“基本稳定”。

### 等价写法（本地实现使用）

令 $m_i$ 为“与第 $i$ 年取值相等的年数”，则

$$
\sum_{p} t_p(t_p-1)(2t_p+5)=\sum_{i=1}^{n}(m_i-1)(2m_i+5)
$$

证明：大小为 $t$ 的一组在右边的求和里出现 $t$ 次，每次贡献 $(t-1)(2t+5)$，
合计 $t(t-1)(2t+5)$，与左边一致。

这种写法可以直接用 numpy 广播实现，不需要先排序或分组：

```python
eq = (x[:, None, :] == x[None, :, :])   # (n, n, k)
m = eq.sum(axis=1)                       # 每一年取值在该像元的重复数
tie_sum = ((m - 1) * (2 * m + 5)).sum(axis=0)
var_s = n * (n - 1) * (2 * n + 5) / 18.0 - tie_sum / 18.0
```

`tests/test_algorithms.py` 在 0—3 的小整数序列（必然含 ties 和真实 0）上
与教科书分组公式逐例比对，确保等价。

## 4. 标准化与连续性修正

$$
Z=\frac{S-1}{\sqrt{\mathrm{Var}(S)}}\quad(S>0)
$$

$$
Z=0\quad(S=0)
$$

$$
Z=\frac{S+1}{\sqrt{\mathrm{Var}(S)}}\quad(S<0)
$$

±1 是**连续性修正**（continuity correction），把离散的 $S$ 往 0 的方向挪半个单位，
让正态近似更保守。样本量 $n \ge 10$ 时正态近似通常可接受；$n<10$ 建议用精确检验。

$Z>0$ 上升倾向，$Z<0$ 下降倾向。

## 5. p 值与判定

双侧检验：

$$
p=2\left(1-\Phi(|Z|)\right)=2\thinspace\Phi(-|Z|)
$$

其中 $\Phi$ 是标准正态分布函数。GEE 里用 `erf` 实现：

```javascript
function normalCDF(z) {
  return ee.Image(z).divide(Math.sqrt(2)).erf().add(1).multiply(0.5);
}
var pValue = ee.Image(1).subtract(normalCDF(Z.abs())).multiply(2).clamp(0, 1);
```

取 $\alpha=0.05$：

- $|Z| \ge 1.96$（等价 $p<0.05$）：拒绝 $H_0$，趋势显著；
- $|Z| < 1.96$：不能拒绝 $H_0$，趋势不显著。

注意“不显著”不等于“没有变化”，只表示在当前样本量下无法与随机波动区分。

## 6. GEE 中的实现细节

文章与常见教程的 GEE 写法：

1. 用 `ee.Join.saveAll('after')` 把每一年与它之后的所有年份配对；
2. `sign = (j != i) * clamp(j - i, -1, 1)`，相等时取 0；
3. 全部 sign 影像求和得到 $S$；
4. ties 修正用数组技巧：把“该取值出现次数 > 1”的年份保留原值，其余置 0，
   得到 `groups`；排序后数每段连续相同值的长度，再套
   $t(t-1)(2t+5)$。

### 数组技巧里 0 的双重身份

`groups = value * (matches > 1)` 会把**非重复年份**变成 0，于是 0 成了“非 ties 哨兵组”。
排序后 0 组排在最前，`groupSizesFromArray` 计算游程长度时恰好丢掉第一组——
这正好丢弃了哨兵组，避免把非重复值误算成 ties。

代价是：**真实取值为 0 的观测也会被并进哨兵组**，它们的重复性不会被计入 ties 修正。
对 NDVI（缩放后几乎不会精确为 0）影响可忽略；对整数 GPP、降水等可能出现真实 0 的变量，
会低估 ties 修正量（方差偏大、$|Z|$ 偏小、结果偏保守）。

本仓库的本地实现（`sen_mk_core.mk_test`）**精确统计所有取值（包括 0）的 ties**，
因此与 GEE 数组技巧在含 0 数据上会有细微差别。正式计算建议用精确版本。

另一个边界情况：所有年份取值完全相同。此时没有“非 ties 哨兵组”以外的游程，
GEE 数组技巧得到的修正量为 0，$\mathrm{Var}(S)$ 未修正；但 $S=0$，
所以 $Z=0$、$p=1$、分类为“基本稳定”，最终分类不受影响。

## 7. 最重要的假设：序列独立

MK 检验假设年份之间相互独立。遥感长时序常存在自相关（今年偏高，明年也偏高），
这会让有效样本量变小、$|Z|$ 虚高、显著性被高估。

本仓库的结果**未做自相关修正**，这是需要在论文/答辩中主动说明的局限。
正式口径可改用：

- **Hamed–Rao 修正**：先估计序列的自相关，修正 $\mathrm{Var}(S)$；
- **预白化（pre-whitening）**：先去掉 AR(1) 结构再做 MK；
- **块 bootstrap / 置换检验**：用重采样构造零分布。

三者各有争议（预白化会削弱真实趋势），选择时应在方法节写清楚。

## 8. 与 Sen 斜率的分工

| | Sen's slope | Mann–Kendall |
|---|---|---|
| 输出 | 变化速率（带单位） | 显著性（Z、p） |
| 是否要求分布 | 否 | 否 |
| 对异常值 | 稳健 | 基于符号，天然稳健 |
| 单独使用的问题 | 无法判断是否显著 | 无法给出变化幅度 |
