# 09 · 常见问题（FAQ）

### 1. Sen 斜率和普通线性回归有什么区别？该用哪个？

Sen 斜率取所有年份对斜率的中位数，对异常值稳健，不要求正态分布；
OLS 最小化残差平方和，对极端值敏感，但能给出 $R^2$、置信区间和残差诊断。

遥感长时序噪声大、异常年份多，趋势幅度优先用 Sen；如果要做驱动归因、
需要控制协变量，再用回归模型。二者不是互斥的，可以并列报告。

### 2. 为什么取中位数而不是均值？

均值会被少数极端配对斜率拉偏。中位数的崩溃点约 29.3%：
只要异常配对少于这个比例，估计就不受影响。

### 3. $n$ 多大才能用正态近似？

常见经验是 $n \ge 10$。$n<10$ 建议用 MK 精确检验（枚举所有排列）。
本仓库的 22 年、24 年都满足。

### 4. 有缺失年份怎么办？

本仓库要求**完整序列**：缺一年的像元整像元不参与。
不建议插值或补 0——插值会平滑掉真实波动，补 0 会制造虚假下降。
如果缺失比例很高，可放宽为“至少 $k$ 年有效”，但必须在方法节说明，
并确保 $S$ 与方差使用同一个 $n$。

### 5. 为什么显著像元比例这么高（96.9%）？

三个原因叠加：

1. 22 年跨度长，单调上升信号强；
2. 研究区几乎全省一致上升；
3. MK 未做自相关修正，正自相关会让 $|Z|$ 偏高。

高比例本身不是错误，但要在论文中说明检验假设与局限。

### 6. p < 0.05 是不是“趋势为真的概率是 95%”？

不是。p 值是在“无趋势”原假设下，观察到当前或更极端结果的概率。
它不等于趋势为真的后验概率，也不衡量趋势幅度。报告时应同时给出
Sen 斜率、p 值、样本量和空间格局。

### 7. 斜率的单位为什么是“每年平方”？

Sen 斜率是“变量单位/年”。GPP 的单位是 g C/m²/year，所以斜率单位是
g C/m²/year 再除以年，即 g C/m²/yr²。NDVI 无量纲，单位是 NDVI·a⁻¹。

### 8. “基本稳定”为什么几乎是空的？

判据是斜率精确等于 0。连续变量（浮点 NDVI、GPP 斜率）几乎不会精确为 0。
这是预期行为。如需“变化可忽略”的稳定区，设置容差阈值，并在方法节写明。

### 9. GPP、NPP、NEP 该选哪个？

- **GPP**：总光合固碳，最大；
- **NPP** = GPP − 自养呼吸；
- **NEP** = NPP − 异养呼吸，更接近净碳汇。

研究“植被生产力/长势”可用 GPP；研究“碳汇”应至少用 NPP，最好用 NEP。
本案例按导师要求用 GPP，解读时不能直接等同于碳汇。

### 10. MK 能检测突变点吗？

不能。MK 检验的是**单调趋势**，不定位突变。突变检测可用
Pettitt 检验、Bayesian 变点分析、BFAST 等。二者可以组合：
先 MK 判断整体趋势，再用变点方法找转折年份。

### 11. 可以用这套方法分析降水、LST、土壤水分吗？

可以，但要注意：

- 降水可能是通量 → 年累加；LST 是状态量 → 年均值/生长季均值；
- 降水有大量 0 值 → ties 修正必须精确（不要用会吞掉 0 的近似实现）；
- 气象序列自相关更强 → 更需要 Hamed–Rao 或预白化；
- 不同变量的趋势方向语义不同，分类名称要改。

### 12. 为什么要把计算搬到本地？

GEE 适合数据获取、年度合成和大区域并行；但当一次请求同时包含多年累加、
数百个年份对、统计和图表时，容易触发容量限制。本地 numpy 对 100 万像元 ×
22 年只需几秒，且完全可复现。分工建议：

- GEE：筛选、QA、年度合成、导出；
- 本地：Sen/MK、分类、面积统计、出图。

### 13. 如何比较两个区域的趋势？

确保：同一产品、同一时段、同一季节窗口、同一年度指标、同一完整序列策略；
然后分别做 Sen + MK，比较斜率分布与五级面积占比。
不要直接比较不同时段或不同产品的斜率。

### 14. 结果能直接用于论文吗？

方法链是标准的，但要注意：

- 补自相关修正或说明局限；
- 给出数据产品版本、QA、年度口径；
- 报告覆盖率与有效面积；
- 趋势解释避免因果化；
- 图件注明投影、比例尺、边界来源。
