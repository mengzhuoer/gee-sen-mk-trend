# 03 · 五级趋势分级与面积统计

## 1. 分级规则

把 Sen 斜率的方向和 MK 的显著性交叉，得到五类：

| 编码 | 类型 | 判定条件 | 配色 |
|---:|---|---|---|
| 1 | 显著退化 | Slope < 0 且 p < 0.05 | `#A50026` 深红 |
| 2 | 不显著退化 | Slope < 0 且 p ≥ 0.05 | `#F46D43` 橙红 |
| 3 | 基本稳定 | Slope = 0 | `#D9D9D9` 灰 |
| 4 | 不显著改善 | Slope > 0 且 p ≥ 0.05 | `#66BD63` 浅绿 |
| 5 | 显著改善 | Slope > 0 且 p < 0.05 | `#006837` 深绿 |

“退化/改善”是变量语义：NDVI、GPP 上升叫改善；若是土壤侵蚀、PM2.5 等变量，
方向含义要相应改写。**编码本身只表示方向，不表示好坏。**

## 2. 判定顺序

五个条件互斥，正常实现不会冲突：

- 先判斜率符号；
- 斜率为 0 的像元单独归 3；
- 其余按 p 值分显著/不显著。

GEE 的 `.where()` 链是“后写的覆盖先写的”，所以条件必须互斥；本仓库的写法：

```javascript
var trendClass = senSlope.multiply(0).toByte()
  .where(senSlope.lt(0).and(pValue.lt(0.05)), 1)
  .where(senSlope.lt(0).and(pValue.gte(0.05)), 2)
  .where(senSlope.eq(0), 3)
  .where(senSlope.gt(0).and(pValue.gte(0.05)), 4)
  .where(senSlope.gt(0).and(pValue.lt(0.05)), 5);
```

本地实现 `classify()` 用布尔索引赋值，语义相同。

## 3. “基本稳定”的陷阱

原文判据是 **Slope 精确等于 0**。对连续变量（NDVI 浮点、GPP 斜率）这几乎不会发生：

- 山西 GPP 案例中，该类别只有 4.7 km²（占 0.003%）；
- 五级图在视觉上接近四级图。

这是预期行为，不是 bug。若业务上需要“变化幅度可忽略”的稳定区，应改成
容差判据，例如：

$$
|\beta| < \beta_{\text{tol}} \quad\Rightarrow\quad \text{基本稳定}
$$

$\beta_{\text{tol}}$ 要按变量量纲和科学问题设定（如 NDVI 取 0.0005/a，
GPP 取 1 g C/m²/yr²），并在方法节明确写出。不要事后为了让图好看而调阈值。

## 4. 面积统计

逐像元算面积，再按类别求和：

```javascript
var areaImage = ee.Image.pixelArea().divide(1e6).rename('area_km2')
  .addBands(trendClass.rename('class'));

var grouped = areaImage.reduceRegion({
  reducer: ee.Reducer.sum().group({groupField: 1, groupName: 'class'}),
  geometry: roi,
  scale: SCALE,
  maxPixels: 1e13,
  tileScale: 4
});
```

要点：

- `ee.Image.pixelArea()` 在 GEE 中按实际投影计算像元面积，不要用“像元数 × 固定面积”；
- 本地实现用球面公式按行计算（见 `sen_mk_local.pixel_area`）；
- 统计分母是**有效分析面积**（完整序列像元），不是行政区的官方总面积；
  报告时要同时给出覆盖率，避免“占比 100%”误导。

山西 GPP 案例：

| 类别 | 面积 km² | 占有效面积 |
|---|---:|---:|
| 1 显著下降 | 405.2 | 0.27% |
| 2 不显著下降 | 1,011.2 | 0.67% |
| 3 基本稳定 | 4.7 | 0.003% |
| 4 不显著上升 | 3,768.0 | 2.48% |
| 5 显著上升 | 146,539.6 | 96.58% |
| **合计** | **151,728.7** | **100%** |

对照山西省官方面积 156,704 km²，有效覆盖约 96.8%。

## 5. 制图建议

- 五级图用**离散色带**（`BoundaryNorm`），不要用连续色带，否则类别边界看不清；
- 图例写全“编码 + 名称 + 判定条件”，不要只写颜色；
- 叠加行政边界时用细黑线，避免盖住专题色；
- 斜率和 Z 值各出一张连续色带图作为附件，正文放五级图；
- 出图时把无数据区设为透明（本地用 `np.where(cls == 0, np.nan, cls)`）。

## 6. 结果解读的三条底线

1. **显著上升占比高 ≠ 生态变好**。GPP 是总光合固碳，碳汇还要扣呼吸；
   NDVI 上升也可能是农业灌溉、种植结构变化。
2. **不显著 ≠ 没变化**。样本量、噪声、自相关都会影响检验功效。
3. **趋势 ≠ 因果**。Sen + MK 只描述时间上的单调性，不解释驱动机制；
   归因需要额外分析（气候、土地利用、政策、矿区等）。
